把工具执行结果发回去

两种格式都要求你把工具的执行结果作为一条新消息追加进去，再发起下一次调用——模型本身从不真正执行任何东西，它只会"提出请求"。

AnthropicOpenAI
一条 user 消息，内容是一个或多个 {type: "tool_result", tool_use_id, content} 内容块 一条 role: "tool" 的消息，带 tool_call_id 和 content
为什么这很重要

不存在唯一的"标准" LLM API。2026 年的现实就是同一套四个概念（指令、历史、工具、计费）有两种不同的表达方式，而市面上其他大部分厂商基本是照抄这两种之一。 waku/loop/models.py 里的 OpenAICompatClient 是一个约 110 行的适配器，专门在边界处把 OpenAI 的格式翻译成 Anthropic 的格式，这样代码库其余部分——循环、工具、trace——就只需要认识一种格式。等你在任何一个产品里第一次要同时支持两个厂商时，这就是一个你必须做的真实架构决策。
